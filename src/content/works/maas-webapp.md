#### 概要

大手航空会社の MaaS Web アプリケーションで、フロントエンド開発を担当しました。ディレクターの数が少なかったため、ディレクション業務も手伝いながらの作業でした。

#### 課題

- ディレクターの数が少なく、開発以外の進行管理や調整にも手が必要だった
- 他社が開発している API と繋ぎこむ必要があり、API の仕様を他社と調整しながら進める必要があった
- Web サイトではなくアプリケーションのため、サイト以上に高いアクセシビリティが求められた

#### 取り組み

1. **ディレクション業務の支援** — フロントエンド開発と並行して、ディレクション業務も手伝いました。
2. **他社 API との繋ぎこみ** — 他社が開発している API との繋ぎこみを担当しました。API の設計の変更願いなど、他社とコミュニケーションをとる機会の多い案件でした。
3. **アクセシビリティの徹底** — アプリケーションであることを踏まえ、サイト以上にアクセシビリティに配慮した実装を徹底しました。

#### 結果と今後

フロントエンド開発だけでなく、ディレクションの支援や他社との API 設計の調整まで、幅広い役割を経験した案件です。
