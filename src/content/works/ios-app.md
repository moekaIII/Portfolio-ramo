#### 概要

毎日の体調や服薬を記録するヘルスケアアプリの iOS 版を、SwiftUI で開発しました。デザイナーと一緒に画面を詰めながら、実装とストア公開まで担当しています。

#### 課題

- 記録が面倒だと続かないため、数秒で入力を終えられる必要があった
- 通信環境が悪い場所でも記録できる必要があった

#### 取り組み

1. **片手で終わる記録** — よく使う項目を画面の下半分に集め、タップだけで記録できる UI にしました。
2. **オフライン対応** — 端末に先に保存し、通信が戻ったときに同期する仕組みにしました。
3. **アクセシビリティ** — Dynamic Type と VoiceOver に対応し、文字を大きくしても崩れないレイアウトにしました。
4. **Web との知見の共有** — Web 版と同じデザイントークンを使い、プラットフォームが違っても同じ印象になるようにしました。

#### 結果と今後

記録の継続率が上がり、App Store でも高い評価をいただきました。Web だけでなく、モバイルアプリまで開発の幅を広げたプロジェクトです。
