#### 概要

自治体が公開している人口・財政・施設利用などの統計データを、グラフで比較・閲覧できる Web ダッシュボードを開発しました。テックリードとして、技術選定、設計方針、コードレビュー、メンバーの育成を担当しています。

#### 課題

- データは表計算ファイルでの公開のみで、住民が読み解くのは難しかった
- 年度ごとに項目名や形式が変わり、そのままでは比較できなかった
- 行政サイトとして、アクセシビリティへの配慮が必須だった

#### 取り組み

1. **データの整形** — 年度ごとに異なる形式を共通のスキーマに変換する仕組みを作り、グラフ側は形式の違いを気にせず扱えるようにしました。
2. **可視化の設計** — 比較したい内容に合わせてグラフの種類を選び、凡例・単位・出典の表記ルールを決めました。
3. **アクセシビリティ** — すべてのグラフに同じ内容の表を用意し、色だけに頼らない表現と、キーボード・スクリーンリーダーでの操作に対応しました。
4. **チームづくり** — Vue 3 の設計方針とレビュー観点をドキュメント化し、経験の浅いメンバーも同じ品質で実装できる体制にしました。

#### 結果と今後

職員が会議資料をダッシュボードから直接作れるようになり、住民からの問い合わせ対応にも使われています。現在は他の分野のデータへ対象を広げています。
